# Nomes dos controles de cores

Os campos de cores agora usam nomes em português que identificam os elementos afetados. Nomes técnicos de paleta e números de tonalidade deixaram de aparecer nos controles.

Exemplos: **Fundo do selo da edição e das seleções**, **Ícones e números de destaque da capa**, **Bordas de cartões e divisórias** e **Borda dos botões Excluir e Remover**.

Os controles de cores compartilhadas também exibem uma descrição com os locais de uso. Essa descrição está associada aos campos para leitura por tecnologias assistivas. Os controles diretos de cabeçalho, botões, menu e rodapé continuam no grupo **Elementos do site**.

Foi removido um seletor complementar sem aplicação, substituído anteriormente pelos controles de degradê. As demais configurações salvas permanecem compatíveis. Esta atualização não exige SQL novo nem redefinição das cores. Publique o projeto atualizado normalmente.

Verificação: build concluído, sete testes existentes aprovados e conferência dos nomes dos controles. A conferência visual no ambiente publicado continua recomendada.
